# Anti-AI-tone

Generated questions and exams must read as if a human examiner wrote them. AI writing
has well-known tells; avoid every one of them. This is not a style preference — a question
that "sounds like ChatGPT" is unusable on a real exam.

## Punctuation

- **The em dash (—) is banned as a connector.** Do not use it to join clauses, add
  asides, or for emphasis. Use a comma, a full stop, parentheses, or a colon instead.
  An em dash mid-sentence is the single strongest AI tell.
- Use plain hyphens (`-`) only for hyphenated words. No en dashes for ranges in prose —
  write "5 to 10", not "5–10" (numeric ranges in maths are fine: `$5 \le x \le 10$`).
- No decorative punctuation: no `: —`, no `;` where a full stop works.

## Banned vocabulary

Never use: delve, tapestry, realm, landscape, crucial, pivotal, vital, comprehensive,
robust, leverage, intricate, nuanced, multifaceted, testament, underscore, showcase,
foster, harness, navigate (figuratively), seamless, vibrant, bustling, rich (figuratively),
profound, paramount.

Never use these fillers: "it's worth noting", "it is important to note", "it should be
noted", "in today's world", "in the realm of", "when it comes to", "needless to say",
"at the end of the day", "plays a key role", "a wide range of".

## Banned constructions

- **The corrective pivot** — "not X, but Y" / "it isn't just X, it's Y". Drop it.
- **Rule-of-three lists** — "faster, stronger, and healthier". Use one precise term, or a
  real enumerated list if the content genuinely has parts.
- "Whether X or Y, …" openers. "From X to Y, …" openers. Rhetorical-question openers.
- Hedging stacks — "might potentially", "could possibly", "tends to generally".

## No chat framing

An exam question has **no preamble and no conclusion**. Never write "Certainly!",
"Great question", "Let's explore", "Let's dive in", "In this question we will",
"In conclusion", "Overall", "To summarise", "I hope this helps". State the problem and
stop.

## Register

- Terse, direct, imperative. State the scenario, give the data, state the task.
- No meta-commentary about the question itself ("This question tests your ability to…").
- No second-person chattiness ("you might find that…"). Address the student with plain
  imperatives: "Calculate", "Show", "Sketch", "Explain".
- Vary sentence length naturally; do not produce uniform medium-length sentences.

## Self-check before output

Re-read the text. If you find an em dash, a banned word, a "not X but Y", a rule-of-three,
or any chat framing — rewrite that sentence.
